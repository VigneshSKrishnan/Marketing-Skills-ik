# ImageKit marketing skills

Claude Code skills for the ImageKit marketing team. This repo is also a Claude Code plugin marketplace (`imagekit-marketing-skills`).

| Skill | What it does |
|---|---|
| [blog-final-check](blog-final-check/README.md) | Checks one ImageKit blog post against the refresh checklist before it is published and gives the writer a report. Report only; never edits the post. |

Install all of them from Claude Code:

```
/plugin marketplace add VigneshSKrishnan/Marketing-Skills-ik
```

Then install a skill, e.g. `/plugin install blog-final-check@imagekit-marketing-skills`. See each skill's README for details and the copy-to-`~/.claude/skills/` alternative.
